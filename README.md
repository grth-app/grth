# GRTH

Pronounced "garth" like the guy from \*_Wayne's World_ or...

**garth** - noun - an open space surrounded by cloisters: _stone-vaulted passageways led into the cloister garth._

This is the very beginning (which you'll see just by looking at the code - it doesn't do _anything_ yet). The idea is to create a place for all of the archives you can download from LinkedIn, Facebook, Twitter, etc, aka "legacy corporate social media" - but not just have a zip file you don't know what to do with. You'll eventually be able to create something from that archive that lives on... a garden.

That's the idea. We'll see what happens!
